# paradise-nursery

**Project name:** paradise-nursery — Paradise Nursery landing page

**Description:** A React plant shop (Paradise Nursery) landing page. The main file is `src/App.css`, which implements the landing page background image — a full-screen photo of lush greenery with a soft dark overlay, `background-size: cover`, and centred positioning, so the heading and text stay readable.

## Main file

- `src/App.css` — landing page styles, including `.landing-page` with `background-image`, `background-size: cover`, `background-position: center`, and a responsive fallback for small screens.
- `src/App.jsx` — the landing page component that uses the `.landing-page` class.

## Run

```sh
npm install
npm start
```
